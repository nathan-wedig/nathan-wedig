## Projetos em Destaque

### Sistema de Gestão Logística e Expedição

Sistema Full Stack desenvolvido para integração com ERP corporativo e automação dos processos de logística e expedição.

**Principais características:**

* Integração com ERP utilizando **IBM DB2**
* Banco de dados auxiliar utilizando **SQLite**
* Arquitetura **Multi-DataSource**
* APIs REST para cargas, pedidos, ordens de compra e relatórios
* Implementação de regras de negócio
* Geração dinâmica de relatórios HTML
* Automação de processos manuais
* Arquitetura multicamadas
* Repository Pattern
* DTO Pattern
* Transaction Management

**Tecnologias:** Java, Spring Boot, Spring Data JPA, Hibernate, React, Material UI, IBM DB2, SQLite e Maven.

### Sistema de Monitoramento da Produção

Dashboard desenvolvido para acompanhamento da produção e visualização de indicadores operacionais em tempo real.

**Principais características:**

* Integração direta com **IBM DB2**
* Indicadores diários e semanais
* Metas de produção por setor
* Detalhamento por ordens, lotes e modelos
* Atualização automática dos indicadores
* Persistência de configurações em JSON
* Dashboard para acompanhamento operacional

**Tecnologias:** Java, Spring Boot, React, IBM DB2, REST APIs e JSON.
