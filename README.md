# Projetos em Destaque

## Sistema de Controle de Manutenção

Sistema full-stack para gerenciamento de manutenções, composto por **API REST em Spring Boot, aplicação web integrada e aplicativo mobile desenvolvido com React Native e Expo**.

O projeto foi desenvolvido com arquitetura em camadas, separando responsabilidades entre Controllers, Services, Repositories, DTOs e Entities.

### Principais características

* Autenticação e autorização utilizando **Spring Security e JWT**
* Controle de acesso baseado em perfis (RBAC)
* Cadastro e gerenciamento de máquinas
* Ordens de serviço
* Controle do ciclo de vida das ordens
* Manutenção preventiva
* Checklists
* Controle de custos
* Gestão de fornecedores e setores
* Dashboard gerencial
* Relatórios em PDF e CSV
* Upload e gerenciamento de documentos
* Identificação de máquinas através de **QR Code**
* Funcionamento offline no aplicativo mobile
* Persistência local e sincronização posterior
* Geração de APK para distribuição Android

### Tecnologias

**Java 17, Spring Boot, Spring Security, JWT, Spring Data JPA, Hibernate, H2, Maven, React Native, Expo, TypeScript, Axios, AsyncStorage e NetInfo.**

[Ver projeto no GitHub](https://github.com/nathan-wedig/controle-manutencao)
